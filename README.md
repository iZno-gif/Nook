# Nook — Offline Android APK Builder

1. Create a new repository on GitHub (e.g. `nook-app`).
2. Upload all files from this folder (including `.github/`, `assets/`, and `www/`) to the repository.
3. Open the **Actions** tab on GitHub — the **Build Nook Android APK** workflow runs automatically (or click **Run workflow**).
4. Once it finishes (~3 minutes), download **nook-app-debug-apk** from **Artifacts**, unzip it on your phone, and install `app-debug.apk`.
